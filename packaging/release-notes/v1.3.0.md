Engine work for mods whose conversations and pickups were written for X-Men Legends I's engine (the community port), and one more engine limit. Drop in the new `dinput.dll`; nothing changes for XML2 as it ships.

### On by default

- **Conversation lines that run by themselves.** A mod marks a line with a negative `timeDelay` and the line goes on once its voice has played (the game never reads the attribute; X-Men Legends I's tours and cutscene chains needed Enter after every line on it). A menu of two or more replies is never picked for the player. Off: `[Game] AutoAdvance=0`.
- **A chosen reply's voice plays out** before its answer; the game used to stop it one frame in (XML2 has six voiced replies, the port 239). Accept skips it. Off: `[Game] ReplyVoices=0`.
- **A reply menu come back to keeps a reply highlighted.** The game's menu builder stored the visible count as the cursor when the previous pick was hidden, so nothing was highlighted and Enter did nothing until up or down. Off: `[Game] ReplyCursor=0`.

### New, when you ask for it

- **`addSkillPoints(name, n)`**, a ninth script function registered with the forced-party ones (`[Game] ForcedTeams` present): one to twenty unspent skill points to the hero named - an item's `onactivate` names the hero who took it as `_ACTIVATOR_` - through the game's own counter, which the skills screen spends from and the save keeps. X-Men Legends I's free-skill-point pickup; the game has no call of its own.
- **`[Limits] ItemEnhancements`** (376 to 1024): the item manager's pool of enhancement records, past which `Data/items` stops loading. XML2's own table uses 374 of 375, so one more enhancement made every later item vanish. Saves store record numbers, so the pool grows at the end of a bigger item manager and nothing moves; the port uses 512.

Every patch checks the bytes it relies on against the retail `XMen2.exe` first; on any other build that feature stays off and `xml2-fix.log` says why. Every setting, with its default: [README -> Settings](https://github.com/ChronoRixun/xml2-fix#%EF%B8%8F-settings-xml2-fixini).

**Install:** copy `dinput.dll` into the folder that contains `XMen2.exe` (replace the old one). See the [README](https://github.com/ChronoRixun/xml2-fix#readme).
