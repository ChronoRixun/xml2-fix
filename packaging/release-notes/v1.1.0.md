- **Console layout.** Pads now get Raven's own console layout, read from the game's console button map: **A** Attack (and accept in menus), **B** Smash (and back in menus), **Y** Jump, **X** Use, **RT** (hold) powers, **RB** Energy Pack, **LT** Call Allies, **LB** Health Pack. 1.0.0's layout had the face buttons in the wrong places, so menus didn't respond to A and B.
- Settings that 1.0.0 set up are moved to the new layout automatically; bindings you changed yourself are left alone.
- Online: the OpenSpy redirect is unchanged, but the game's lobby isn't usable on OpenSpy yet (no regions are set up for XML2 there). See the README.
