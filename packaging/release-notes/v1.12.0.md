# XML2 Fix 1.12.0-beta.1: Remastered preview

This is pre-release preparation. Stable is the 1.11.1 line (Skirmish weekend patch); this preview is built on 1.11.1. Remastered is optional and off by default.

- Optional MSAA requests (saved native setting, 2/4/6/8 samples, supported fallback).
- Optional draw-scoped anisotropic filtering for eligible named world textures; point-sampled world art has a separate opt-in. Interface texture sampling is preserved.
- Optional proportional, centered Beenox Advanced options panels on wide screens. HUD, dialogue and world projection keep the released geometry.
- CaptureBackBuffer=0 permits MSAA while retaining test-pipe input/status; backbuffer screenshot commands are disabled in that mode.
- Settings are read on game restart. Disabling the master profile keeps component choices for later.

The intended companion content is the unchanged Legends Classic 0.6.1 (content 39 / LC49), the same as stable 1.11.1. No rebuild is required solely to change these graphics settings. The proposed Ultimate Legends companion UI is prepared separately; manual INI settings are documented in docs/remastered.md.

Mixed Remastered ON/OFF peers are allowed when the existing gameplay/content agreement matches. These options affect rendering and native panel hit-test geometry, without changing simulation input, RNG, time, camera or gameplay rules. They add no agreement identity.

Validation and remaining limits must be checked against the work-folder GO-CHECKLIST before promotion. Native/driver quality, real focus changes, physical DPI/controller behavior and other GPU vendors are distinct checks. No real Steam Deck certification is implied by WSL/Proton testing. DXVK is not bundled by this candidate; the test pin is v3.1.1.
