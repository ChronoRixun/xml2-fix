# XML2 Fix 1.12.0-beta.1: Remastered preview

A preview of **Remastered**, an optional set of graphics upgrades, built on the stable **XML2 Fix 1.11.1**. It is off by
default and only changes how your own screen is drawn.

- **Anti-aliasing (MSAA):** smoother edges (2/4/6/8 samples, with a safe fallback if your GPU can't do the choice).
- **Anisotropic filtering:** sharper floors and walls at an angle, for world textures only; menus and HUD keep their
  original look.
- **Centered menus:** the Advanced options panels are proportional and centered on wide screens. HUD, dialogue and the
  game camera are unchanged.
- Settings are read when the game starts. Turning Remastered off keeps your choices for next time.

**Plays with stable:** Remastered adds nothing to the shared game rules, so beta players (Remastered on or off) and stable
1.11.1 players can host and join each other. Legends Classic stays 0.6.1 - no rebuild needed.

**How to turn it on (for now):** close the game, open `xml2-fix.ini` next to `dinput.dll` in your game folder and add:

```ini
[Remastered]
Enabled=1
MSAASamples=4
Anisotropy=16
CenteredHud=1
```

`MSAASamples=0` uses the anti-aliasing choice from the game's own Advanced options instead. A Remastered page in Ultimate
Legends comes later with the settings page redesign.

**Tested:** boots with Remastered on and off, online pairing with stable 1.11.1 in both directions, and a hand check
(alt-tab, controller, Advanced options, zone change) with Legends Classic on an NVIDIA PC. Not yet checked: AMD/Intel GPUs and a real Steam
Deck - tell us how it looks on yours. DXVK is not included.
