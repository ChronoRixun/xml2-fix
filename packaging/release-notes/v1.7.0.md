# XML2 Fix 1.7.0

The engine half of Legends Classic 0.2.4: enemy resistance text returns and
online conversations stop putting the two games out of step.

- **Enemy resistance text:** `[Game] ResistanceDisplay=xml1` shows the first
  game's colored Physical Resistant, Energy Resistant and Mental Resistant
  text beneath the target health bar. This changes the display only; damage
  and resistance rules stay the same. Absent or `xml2` keeps the previous display.
- **Co-op conversations:** `[Game] OnlineConversations=lockstep` makes lines
  that advance by themselves advance at the same game time on both PCs.
  Previously each PC waited for its own voice clip to end, which could put
  the games out of step and drop the session. Online, a selected reply no
  longer plays its full voice line; single-player is unchanged.

**Updating Legends Classic:** in Ultimate Legends, **Rebuild**, then **Play**.
Both PCs need builder **0.2.4** and **XML2 Fix 1.7.0**. The builder enables both
settings. Launcher 0.3.2 already supports this pair; no launcher release is needed.
The save format is unchanged. The builder's HAARP boss-map correction can reset
an older saved record for that encounter.

**Ordinary X-Men Legends II installs:** both new settings are off by default.
Copy `dinput.dll` next to `XMen2.exe`; no new setting is required.

**Known limits:** Legends Classic's solo story segments still leave the second
online player without a hero, and co-op New Game starts with Wolverine alone
(#106, planned for 0.3.0). Use Load Saved Campaign and restart from a save after
a solo segment. The conversation fix was compared in two copies on one PC;
two-PC/internet testing remains outstanding.

These settings add no save field. ResistanceDisplay adds no agreement rule;
OnlineConversations uses rule 27 revision 1, so both peers must match. An earlier
0.2.4a candidate is refused at join. See the [builder's release notes](https://github.com/ChronoRixun/legends-classic/releases/tag/v0.2.4)
for the port's content changes and remaining known issues.
