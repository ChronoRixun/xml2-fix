First release.

- **Controllers work out of the box.** Xbox and other XInput pads are bound to a console-style layout the first time you start the game, for up to four players; no more binding 42 actions by hand in Advanced options.
- **Online play via OpenSpy.** The game's GameSpy lookups go to OpenSpy's replacement servers (configurable with `xml2-fix.ini`).

Install: copy `dinput.dll` into the folder that contains `XMen2.exe`. See the [README](https://github.com/ChronoRixun/xml2-fix#readme) for the full button layout.
