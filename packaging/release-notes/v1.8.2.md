XML2 Fix 1.8.2 is a hotfix for 1.8.1, the engine half of Legends Classic 0.4.0 (content 27, lobby token `LC36`),
with Ultimate Legends launcher 0.4.0.

- **Steam Deck / Proton: the game no longer stops on a black screen at start.** Since 1.8.1, the game could hang on
  a black screen before the main menu under Proton or Wine (Steam Deck, Linux). XML2 Fix's background controller
  check waited for itself there. It no longer does, and under Proton / Wine the controller check now runs the old way
  by default (`[Input] CacheDeviceScan = 1` in `xml2-fix.ini` turns the background check back on). Should a
  controller list ever take over 10 seconds, the game now carries on instead of waiting forever
  ([details](https://github.com/ChronoRixun/xml2-fix/blob/v1.8.2/docs/controller-scan-cache.md)).
- **Windows: nothing changes.** The once-a-second pause fix from 1.8.1 stays on.

**How to update.** In Ultimate Legends (Stable channel), update **XML2 Fix to 1.8.2** and **Play**. No Rebuild is
needed and the builder stays 0.4.0. Saves carry over; the save format is unchanged.

**Co-op:** 1.8.2 changes no gameplay rule, so 1.8.2, 1.8.1 and 1.8.0 PCs play together (the same Legends Classic
0.4.0 build on all of them). Everything else is 1.8.1's and 1.8.0's, including the known issues
([1.8.1 release notes](https://github.com/ChronoRixun/xml2-fix/releases/tag/v1.8.1),
[1.8.0 release notes](https://github.com/ChronoRixun/xml2-fix/releases/tag/v1.8.0)).

**Packaging:** as 1.8.1 - pinned GameNetworkingSockets, protobuf and the project CA linked statically into
`dinput.dll`, checked by `scripts/check_release_dll.py`; Windows system imports only.
