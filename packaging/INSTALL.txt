XML2 Fix
Xbox controllers, display options, Discord presence & online play for X-Men Legends II (PC)
https://github.com/ChronoRixun/xml2-fix

INSTALL
  Copy dinput.dll into the game's folder - the one that contains XMen2.exe.
  Start the game: your controller is already bound (Options > Controls > Advanced to change it).

UNINSTALL
  Delete dinput.dll (and xml2-fix.ini / xml2-fix.log, if there) from the game folder.

SETTINGS
  No settings file is needed. To change something, create xml2-fix.ini next to the DLL (the
  Ultimate Legends launcher can edit it for you). A value ends at the first ";" (the rest is a
  comment); an empty value is the same as no key: the default. Every key is listed in the README:
  https://github.com/ChronoRixun/xml2-fix#%EF%B8%8F-settings-xml2-fixini

ON BY DEFAULT, AND HOW TO SWITCH EACH OFF
  Pad button prompts         [Input]   Prompts=off      (or keyboard; PromptColors=0 for plain [A] text)
  Discord Rich Presence      [Discord] Enabled=0        (or ShowZone=0 / ShowParty=0 to share less)
  OpenSpy online redirect    [Online]  Domain=off
  LocalIP (hosting address)  [Online]  LocalIP=first
  Four rows in Advanced      [Display] InGameOptions=0
  Mods folder                remove or empty the "mods" folder
  Everything else is off until you set it.

BUTTON PROMPTS
  Players on a pad see the pad's buttons in prompts (A, B, X, Y in their colours) instead of
  keyboard keys. Each player's prompts follow the device they last used.

DISCORD
  With the Discord app running, your Discord profile shows the zone, your heroes and their levels,
  and the mode (menus, cutscene, Danger Room, online). No player names, no PC, network or account
  details. It goes to the Discord app on this PC only; Discord shows it to whoever it shows your
  activity to.

ONLINE
  The game's GameSpy servers are gone; the game's online lookups go to OpenSpy (openspy.net), an
  independent community service, instead. The game only talks to it from its Play Online menu on.
  The online lobby isn't usable on OpenSpy yet (no regions are set up for the game there).
    [Online]
    Domain=openspy.net      (or your own server's domain, or: off)
    Server=                 (an IPv4 address every GameSpy lookup goes to; wins over Domain)
    LocalIP=auto            (first = Windows' order, as without the fix, or one of this PC's addresses)
  Note: an empty Domain= now means openspy.net; only Domain=off switches the redirect off.

DISPLAY (optional)
  The game only runs in exclusive fullscreen and switches your monitor to the resolution in its
  settings. The same settings are in the game under Options > Controls > Advanced, or in
  xml2-fix.ini:
    [Display]
    Mode=borderless         (fullscreen, borderless or windowed; leave out for the game's own)
    Width=0                 (force a resolution; 0 = the desktop size (borderless) or the game's setting)
    Height=0
    Topmost=0               (1 keeps the game above other windows)
    RunInBackground=1       (0 pauses the game when it loses the focus, like the stock game)
    FrameRate=refresh       (fps, "refresh" = your desktop's rate, or 0 = unlimited; leave out for
                             the game's own 60 fps cap; menus stay at 60)
    VSync=0                 (1 or 0; leave out for the engine's own setting)
    ResolutionList=all      (up to 64 sizes in Options > Video, in every mode; game = at most the
                             game's own 20; leave out for the game's own list)
  In a window VSync=1 paces frames at your desktop's refresh rate (Direct3D 8 has no usable vsync
  there); it never goes above FrameRate.

MODS
  Put each mod in its own folder under "mods" next to the game, laid out like the game folder; the
  game's own files stay untouched. mods\load-order.txt: one line per mod, +Name on, -Name off,
  later lines win. Folders it doesn't list load after the listed ones. The mods are read when the
  game starts.

BIGGER ZONES (for mods that need it)
    [Limits]
    ActorSlots=127          (41-127; the game's own is 40)
    ResourceNames=1024      (451-4096; the game's own is 450)

TROUBLESHOOTING
  The fix writes xml2-fix.log next to itself each time the game starts. If something is wrong,
  open an issue on GitHub and attach that file. The log can hold this PC's name, its local
  network addresses and folder paths: look it over before posting it publicly.
  [Debug] LogNetwork=1 logs the game's online traffic; LogFiles=1 every file the game opens.
