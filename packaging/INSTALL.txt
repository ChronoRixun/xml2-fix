XML2 Fix
Xbox controllers & online play for X-Men Legends II (PC)
https://github.com/ChronoRixun/xml2-fix

INSTALL
  Copy dinput.dll into the game's folder - the one that contains XMen2.exe.
  Start the game: your controller is already bound (Options > Controls > Advanced to change it).

UNINSTALL
  Delete dinput.dll from the game folder.

ONLINE
  The game's GameSpy servers are gone; the fix sends its online lookups to OpenSpy
  (openspy.net) instead. To use a different server, or to switch this off, create
  xml2-fix.ini next to the DLL:
    [Online]
    Domain=openspy.net      (or your own server's domain, or: off)

DISPLAY (optional)
  The game only runs in exclusive fullscreen and switches your monitor to the resolution
  in its settings. To run it in a window at your desktop's resolution instead, add to
  xml2-fix.ini next to the DLL:
    [Display]
    Mode=borderless         (fullscreen, borderless or windowed; leave out for the game's own)
    Width=0                 (force a resolution; 0 = the desktop size (borderless) or the game's setting)
    Height=0
    Topmost=0               (1 keeps the game above other windows)
    RunInBackground=1       (0 pauses the game when it loses the focus, like the stock game)
    FrameRate=refresh       (fps, "refresh" = your desktop's rate, or 0 = unlimited; leave out for the game's own 60 fps cap)
    VSync=0                 (1 or 0; leave out for the engine's own setting)
  In every mode your desktop resolution appears in Options > Video. FrameRate and VSync work in
  any mode, the game's own included. In a window VSync=1 paces frames at your desktop's refresh
  rate (Direct3D 8 has no usable vsync there); it never goes above FrameRate.

TROUBLESHOOTING
  The fix writes xml2-fix.log next to itself each time the game starts.
  If something is wrong, open an issue on GitHub and attach that file.
